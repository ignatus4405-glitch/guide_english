# Руководство пользователя

Guide English — настольная программа для изучения английского языка на Windows 10/11. Внутри: грамматика с объяснениями на русском, аудирование с озвучкой, словарь и тренировка. Интернет не обязателен — нужен только для проверки обновлений.

## Установка

1. Откройте [страницу последнего релиза](https://github.com/ignatus4405-glitch/guide_english/releases/latest).
2. Скачайте один из файлов:

   | Файл | Что это |
   |---|---|
   | `Guide-English-Setup-<версия>.exe` | Установщик: ярлык в меню «Пуск», автоматические обновления |
   | `Guide-English-Portable-<версия>.exe` | Портативная версия: запускается без установки, обновляется вручную |

3. Запустите файл. Если Windows SmartScreen предупреждает о неизвестном издателе: **«Подробнее» → «Выполнить в любом случае»**. Сборка не подписана платным сертификатом, это нормально.
4. Установщик предложит выбрать папку и создать ярлыки. Права администратора нужны только при установке в `Program Files`.

## Первый запуск

- Откроется главный экран с общим прогрессом и рекомендацией, что изучать дальше.
- Прогресс сохраняется автоматически на этом компьютере (файл в `%APPDATA%\Guide English\`).
- Тема оформления и скорость речи настраиваются в разделе **⚙️ Настройки**.

## Как заниматься

1. **📚 Грамматика** — выберите тему. Сначала прочитайте правило и таблицу, затем примеры (кнопка 🔊 озвучивает фразу), затем пройдите тест. После каждого ответа появляется разбор.
2. **🎧 Аудирование** — откройте урок и нажмите «▶ Слушать весь текст». Предложения подсвечиваются; можно нажать на любое предложение, чтобы прослушать только его. Меняйте скорость (0.5–1.4×) и голос. Ответьте на вопросы — при ≥ 66 % верных урок отмечается пройденным.
3. **🃏 Словарь** — слушайте слово (🔊), читайте перевод и пример, отмечайте «знаю». Кнопка «🎯 Тренировать слова» запускает викторину.
4. **🧩 Тренировка** — 10 случайных вопросов из всех разделов, результат с пояснениями.

Рекомендуемый режим: 15–20 минут в день, одна тема грамматики + один урок аудирования + 10 слов.

## Английские голоса в Windows

Озвучка использует системные голоса Windows. Если английских голосов нет или они звучат неестественно:

1. **Параметры → Время и язык → Язык и регион** → добавьте «English (United States)» или «English (United Kingdom)».
2. **Параметры → Специальные возможности → Речь** (или «Голос») → выберите английский голос → «Добавить».
3. Перезапустите Guide English и выберите голос в **Настройках**.
4. Если английский голос не появился, установите языковой пакет с компонентом «Речь» в параметрах языка.

Совет: для аудирования ставьте скорость 0.8–0.9× на начальном уровне и 1.0× на среднем.

## Обновления

- Установленная версия проверяет GitHub Releases через 5 секунд после запуска и далее каждые 4 часа.
- При выходе новой версии появляется баннер, системное уведомление и прогресс загрузки.
- Когда обновление скачано, нажмите **«Перезапустить и обновить»** (или согласитесь в диалоге). Прогресс и настройки сохраняются.
- Проверить вручную: кнопка в левом нижнем углу, меню **Помощь → Проверить обновления** или **Настройки → Проверить сейчас**.
- Портативная версия автоматически не обновляется: скачайте новый `Portable` и замените файл.

| Клавиши | Действие |
|---|---|
| `Ctrl + F` | Поиск по темам, урокам и словам |
| `Space` | Остановить озвучку |

| `F11` | Полный экран |
| `Alt` | Показать меню приложения |

## Данные и приватность

- Приложение не собирает телеметрию и не отправляет ваши ответы.
- Прогресс хранится локально: `%APPDATA%\Guide English\guide-english-store.json`.
- Сброс прогресса: **Настройки → Сбросить прогресс** или кнопка «↺ Сбросить» вверху.
- Удаление: «Параметры → Приложения» или `Uninstall Guide English.exe`. Данные прогресса при удалении сохраняются; удалите папку `%APPDATA%\Guide English`, если они не нужны.

## Частые вопросы

**Нет звука.** Проверьте системный звук, выбранный голос и громкость в настройках приложения. Убедитесь, что в Windows установлен английский речевой голос.

**Антивирус/SmartScreen ругается.** Сборка не имеет платной подписи; скачивайте файлы только со страницы Releases этого репозитория. При желании проверьте SHA-256 через `latest.yml`.

**Обновление не приходит.** Проверьте интернет, что установлена именно Setup-версия (не Portable), и нажмите «Проверить обновления». Устаревшие релизы не удаляются — клиент смотрит на последний.

**Можно ли учиться без интернета?** Да, весь контент и озвучка локальные. Интернет нужен только для обновлений.
