# План развития

Документ помогает следующему агенту понять, что уже сделано и куда двигаться. Приоритеты не жёсткие — обсуждайте в issue.

## Сделано (v0.1.x)

- [x] Каркас Electron-приложения для Windows с безопасным IPC.
- [x] 10 тем грамматики A0–B1 с объяснениями, таблицами, примерами и тестами.
- [x] 9 уроков аудирования A1–B2 с TTS, выбором голоса и скорости.
- [x] Словарь и тренажёр слов, смешанная тренировка.
- [x] Локальный прогресс, тёмная тема, поиск.
- [x] CI: тесты данных, jsdom smoke-тест, синтаксис, синхронность документации.
- [x] Автоматические релизы по Conventional Commits + автообновление клиента.

## Ближайшие задачи

- [ ] **Больше контента**: Present Perfect Continuous, косвенная речь, фразовые глаголы; ещё 6–9 уроков аудирования B2; тематические наборы слов (еда, работа, здоровье).
- [ ] **Интервальное повторение** (SRS) для словаря: коробки Лейтнера, ежедневная очередь повторений.
- [ ] **Статистика**: график занятий по дням, серия дней (streak), слабые темы.
- [ ] **Экспорт/импорт прогресса** в JSON для переноса между компьютерами.
- [ ] **Тренировка произношения**: запись микрофона и сравнение с эталоном (Web Audio API).
- [ ] **Экзамен-режим**: итоговый тест по уровню с сертификатом-картинкой.

## Правила для новых задач

1. Обновите этот файл, если задача меняет приоритеты.
2. Следуйте `docs/AGENTS.md`: тесты → документация → Conventional Commits.
3. Крупные фичи дробите на PR, чтобы авто-релизы оставались осмысленными.
