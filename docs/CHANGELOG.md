# История изменений

Все заметные изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

Записи для новых версий добавляются автоматически workflow `Release` из Conventional Commits.
Ручные записи о нерелизных изменениях можно добавлять в раздел «Unreleased».

## Unreleased

### Добавлено

- Полноценное приложение Guide English для Windows на Electron.
- Раздел «Грамматика»: 10 тем A0–B1 с объяснениями на русском, таблицами, примерами, блоком «частая ошибка» и тестами с разбором.
- Раздел «Аудирование»: 9 уроков трёх уровней, TTS-озвучка, выбор голоса, скорость 0.5–1.4×, подсветка предложений, вопросы на понимание.
- Раздел «Словарь»: карточки слов с транскрипцией, примером, озвучкой и тренажёром.
- Смешанная тренировка, глобальный поиск, тёмная тема.
- Локальное сохранение прогресса (`electron-store`) и сброс прогресса.
- Автообновления через GitHub Releases (`electron-updater`): проверка при запуске и каждые 4 часа, баннер, прогресс загрузки, установка в один клик.
- CI (тесты, валидация контента, проверка документации) и Release workflow с авто-версионированием по Conventional Commits, сборкой NSIS/portable и публикацией релиза.
- Документация для агентов: архитектура, гайд по контенту, процесс релиза, индекс контента.
