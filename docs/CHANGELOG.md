# История изменений

Все заметные изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

Записи для новых версий добавляются автоматически workflow `Release` из Conventional Commits.
Ручные записи о нерелизных изменениях можно добавлять в раздел «Unreleased» перед первым релизом.

## Unreleased

### Изменено

- Интерфейс полностью переработан в стиле Duolingo: путь из разделов и узлов, липкие баннеры разделов, 3D-кнопки, маскот-сова, крупные варианты ответов.
- Урок стал полноэкранным: полоса прогресса, сердца, зелёный/красный разбор после каждого ответа, экран результата с конфетти и XP.
- Правила и объяснения встроены в урок как карточка перед упражнениями; справочник открывает их отдельно.

### Добавлено

- Геймификация: сердца с регенерацией (1 за 30 минут), серия дней с заморозкой, XP и уровни, самоцветы, дневная цель, 12 достижений.
- Магазин: восстановление сердец, двойной XP на 15 минут, заморозка серии.
- Раздел «Практика»: смешанная тренировка, работа над ошибками (ошибки запоминаются), быстрый вход в аудирование, слова и грамматику.
- Профиль с уровнем, статистикой, серией и достижениями.
- Звуковые эффекты на Web Audio API (без аудиофайлов), переключатель в настройках.
- `src/data/course.js` — учебный путь, достижения и товары; `src/renderer/core.js` и `src/renderer/lesson.js` — состояние и движок урока.
- Тесты курса и обновлённые jsdom smoke-тесты интерфейса.

## Первый выпуск — что уже есть

### Добавлено

- Полноценное приложение Guide English для Windows на Electron.
- Раздел «Грамматика»: 10 тем A0–B1 с объяснениями на русском, таблицами, примерами, блоком «частая ошибка» и тестами с разбором.
- Раздел «Аудирование»: 9 уроков трёх уровней, TTS-озвучка, выбор голоса, скорость 0.5–1.4×, подсветка предложений, вопросы на понимание.
- Раздел «Словарь»: карточки слов с транскрипцией, примером, озвучкой и тренажёром.
- Смешанная тренировка, глобальный поиск, тёмная тема.
- Локальное сохранение прогресса (`electron-store`) и сброс прогресса.
- Автообновления через GitHub Releases (`electron-updater`): проверка при запуске и каждые 4 часа, баннер, прогресс загрузки, установка в один клик.
- CI (тесты, валидация контента, проверка документации) и Release workflow с авто-версионированием по Conventional Commits, сборкой NSIS/portable и публикацией релиза.
- Документация для агентов: архитектура, гайд по контенту, процесс релиза, индекс контента.
